# -aict-cloud-assignment-2
This is the ICT assignment 2.
##Purpose
- A Python project used to practise five cloud tools: Google Colab (run),
- GitHub (store), Google Drive/OneDrive (share evidence), GitHub Pages (publish) and
- Overleaf (report). The program summarises a set of sensor readings.

##Reading
- This is an array with readings 22, 24, 26, 28, 30

 - Minimum: 22
